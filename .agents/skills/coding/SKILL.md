# Lead Python & Systems Engineering Skill

## Core Principles
1. **Zero-Trust Security & Fail-Closed Defaults**: Never fall back to unauthenticated or insecure modes in production. Reject placeholders, malformed secrets, and untrusted inputs.
2. **Deterministic State & Idempotency**: State mutations, circuit breakers, and ledgers must be crash-resilient with atomic updates, proper rollback, and directory fsync durability.
3. **Strict Type Safety & Contract Adherence**: Use Python typing, runtime validations, and explicit schema definitions to prevent silent failures.
4. **Behavioral Testing First**: Write regression tests that exercise real code paths with actual assertions rather than mocked trivialities.
